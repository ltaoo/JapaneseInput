每个假名，都给一个中文记忆提示

先看字形联想，再读罗马音，最后用短词把声音固定下来。全表按常用的 46 个基本假名整理，同时给出平假名和片假名的记形提示。

「字源」列引用前文资料；「形状联想」是为记忆编的提示，不是逐笔的历史演变过程。看不出草书原形时，直接用形状故事即可。

中文近音只是回忆标签，不是音标。え行的 e 是单元音，借“诶”的开头、去掉尾音 i；う的嘴唇放松；ら行的 r 用舌尖轻点。中文没有贴切近音的 tsu 等音，按罗马音组合并跟音频校准。

每次任选 3～5 个。看一遍，遮住罗马音，再打乱读；认出后再加下一组。把“不留圈的ろ／留圈的る”等成对比较。

あ行

  • あア

    a

    平假名形状：把「安」想成草写：上面一横一竖，下面绕一圈。看见圈，就张口说“啊”。

    读音提示：a：用“啊”作近音提示。

    片假名形状：ア像一个斜着的「了」，下方伸出一撇；和あ共用“啊”的提示。

    字源：あ ← 安；ア ← 阿。

    アイスクリーム／aisukuriimu／冰淇淋

  • いイ

    i

    平假名形状：把「以」简化成左右分开的两笔，像并排站着的两个人。

    读音提示：i：用“衣”作近音提示。

    片假名形状：イ就是「伊」左边的「亻」：一撇、一竖。

    字源：い ← 以；イ ← 伊。

    アイスクリーム／aisukuriimu／冰淇淋

  • うウ

    u

    平假名形状：上面一点像乌鸦的小脑袋，下面的弯像身体：乌鸦，う。

    读音提示：u：“乌”帮助回忆；实际发音时嘴唇放松，别用力噘圆。

    片假名形状：ウ像「宇」上面的「宀」，保留小点和屋顶。

    字源：う ← 宇；ウ ← 宇。

    ウール／uuru／羊毛

  • えエ

    e

    平假名形状：看成戴了一顶小帽、尾巴伸长的「元」。帽子一点，下面拐弯。

    读音提示：e：借“诶”的开头找音，去掉后面的 i，保持一个元音。

    片假名形状：エ看成「江」右边的「工」，三笔就能写出来。

    字源：え ← 衣；エ ← 江。

    エレベーター／erebeetaa／电梯

  • おオ

    o

    平假名形状：看成「才」的竖钩绕了一个圈，右上角还留着一点。

    读音提示：o：用“哦”作近音提示，元音保持稳定。

    片假名形状：オ像「才」，想成张嘴说“哦”的人才；这是记形联想。

    字源：お ← 於；オ ← 於。

    ラジオ／rajio／收音机、广播

か行

  • かカ

    ka

    平假名形状：像「力」旁边多了一点：想象发出“咔”的一声。

    读音提示：ka：用“咔”作近音提示。

    片假名形状：カ直接联想「加」左边的「力」，比か少了旁边的小点。

    字源：か ← 加；カ ← 加。

    カメラ／kamera／相机

  • きキ

    ki

    平假名形状：上面两横，下面一个弯；把它想成一把钥匙，英语 key 也能提示 ki。

    读音提示：ki：k 接「い」的 i；也可借英语 key 回忆。

    片假名形状：キ像钥匙杆上有两道齿，两横穿过一根斜杆。

    字源：き ← 幾；キ ← 幾。

    ケーキ／keeki／蛋糕

  • くク

    ku

    平假名形状：像从侧面看一张张开的嘴，嘴里正在“哭”。

    读音提示：ku：“哭”帮助回忆；う的嘴唇要放松。

    片假名形状：ク像「夕」少了里面的一点；张嘴“哭”的提示仍然适用。

    字源：く ← 久；ク ← 久。

    ミルク／miruku／牛奶

  • けケ

    ke

    平假名形状：左边一根门框，右边一个十字门轴；给这扇门挂上字母 K。

    读音提示：ke：借字母 K 的开头，去掉尾音 i；也就是 k 接え。

    片假名形状：ケ像半个竹字头伸长了腿；给它也挂一个 K 标签。

    字源：け ← 計；ケ ← 介。

    ケーキ／keeki／蛋糕

  • こコ

    ko

    平假名形状：「口」左右两边打开，只留下上、下两道横线。

    读音提示：ko：借“口”kǒu 的开头，收掉尾音 u，保持纯 o。

    片假名形状：コ像「口」去掉左边的一竖；和こ的“两横”放在一起记。

    字源：こ ← 己；コ ← 己。

    コーラ／koora／可乐

さ行

  • さサ

    sa

    平假名形状：き上面有两横，さ少一横；想象钥匙的零件“撒”落了一根。

    读音提示：sa：用“撒”作近音提示。

    片假名形状：サ像「艹」的两根竖笔往下伸；想象草籽“撒”下去。

    字源：さ ← 左；サ ← 散。

    サラダ／sarada／沙拉

  • しシ

    shi

    平假名形状：一笔弯下来的长钩，像一根“吸”管。

    读音提示：shi：用“吸”作近音提示；不是汉语拼音 shī。

    片假名形状：シ的两点偏竖排，最后一笔从左下向右上挑；想象竖着的吸管。

    字源：し ← 之；シ ← 之。

    タクシー／takushii／出租车

  • すス

    su

    平假名形状：「寸」的竖钩打了个小圈；把这个圈想成苏打水的气泡。

    读音提示：su：“苏”帮助回忆；う要放松、收短。

    片假名形状：ス像「久」少了最上面的一撇，下面分出两条腿。

    字源：す ← 寸；ス ← 須。

    バス／basu／公交车

  • せセ

    se

    平假名形状：把「世」中间的笔画收简，最下面的一横写弯。

    读音提示：se：s 接え的 e；“色”只能作标签，不直接照拼音 sè 读。

    片假名形状：セ像「七」的右上方又多一根短竖，底下仍有弯钩。

    字源：せ ← 世；セ ← 世。

    セーター／seetaa／毛衣

  • そソ

    so

    平假名形状：上面先折两下，下面绕个弯，像把一根线折好再收起来。

    读音提示：so：借“搜”sōu 的开头，收掉尾音 u。

    片假名形状：ソ像一只眼睛加一条向左下落的长撇；和末笔上挑的ン成对记。

    字源：そ ← 曽；ソ ← 曽。

    ソファー／sofaa／沙发

た行

  • たタ

    ta

    平假名形状：把「太」想成快写后左右分开：左边像十，右边留两小笔。

    读音提示：ta：用“他”作近音提示。

    片假名形状：タ像「夕」，里面有一小笔；和少这小笔的ク成对记。

    字源：た ← 太；タ ← 多。

    タクシー／takushii／出租车

  • ちチ

    chi

    平假名形状：把「七」的长笔继续往下绕弯，就有点像数字 5。

    读音提示：chi：用“七”帮助回忆；日语 chi 的送气不要像普通话 q 那么强。

    片假名形状：チ看成「千」：短撇、横线、向下的一笔。

    字源：ち ← 知；チ ← 千。

    チーズ／chiizu／奶酪

  • つツ

    tsu

    平假名形状：一笔弯成鱼钩，钩尖朝左；整条弯线像一股流水。

    读音提示：tsu：ts 接う，合成一拍；中文没有贴切的单字近音。

    片假名形状：ツ的两点偏横排，最后一笔从右上向左下落；两点像并排的小鱼。

    字源：つ ← 川；ツ ← 川。

    ツナ／tsuna／金枪鱼食品、罐头

  • てテ

    te

    平假名形状：把「天」快写成一横，下面接一条向下弯的长笔。

    读音提示：te：t 接え的 e；借“诶”的开头，保持纯元音。

    片假名形状：テ像「丁」上面再加一横，把下方长笔写成斜撇。

    字源：て ← 天；テ ← 天。

    テニス／tenisu／网球

  • とト

    to

    平假名形状：一小点落进下面的一只弯碗，像把「卜」写弯了。

    读音提示：to：t 接お的 o；“托”可作标签，实际元音保持纯 o。

    片假名形状：ト几乎就是「卜」，一竖旁边伸出短短的一笔。

    字源：と ← 止；ト ← 止。

    トマト／tomato／番茄

な行

  • なナ

    na

    平假名形状：左边十字，右边一点和一个结；想象伸手把绳结“拿”起来。

    读音提示：na：用“拿”作近音提示。

    片假名形状：ナ像「十」的竖笔向左撇出去；像伸手“拿”东西。

    字源：な ← 奈；ナ ← 奈。

    バナナ／banana／香蕉

  • にニ

    ni

    平假名形状：把「仁」左边的亻写弯一点，右边仍然像「二」。

    读音提示：ni：用“泥”作近音提示。

    片假名形状：ニ就是两条横线，直接看成汉字「二」。

    字源：に ← 仁；ニ ← 二。

    テニス／tenisu／网球

  • ぬヌ

    nu

    平假名形状：把「女」写得绕一点，尾巴留一个小圈；小圈像一团“怒”气。

    读音提示：nu：“怒”帮助回忆；う的嘴唇放松。

    片假名形状：ヌ看成两笔交叉的「又」，和ぬ下方交叉的感觉放在一起记。

    字源：ぬ ← 奴；ヌ ← 奴。

    ヌードル／nuudoru／面条、面类

  • ねネ

    ne

    平假名形状：左边一根杆，右边绳子打结；尾端的小圈，就是系绳子的结。

    读音提示：ne：n 接え；“呢”只作回忆标签，不直接照普通话 ne 读。

    片假名形状：ネ像「礻」向右又伸出一小笔；联系字源「祢」记形。

    字源：ね ← 祢；ネ ← 祢。

    ネクタイ／nekutai／领带

  • のノ

    no

    平假名形状：一笔画出一个斜圈；在圈里想象写着英语 NO。

    读音提示：no：借英语 no 回忆，但元音保持纯 o，不往 u 滑。

    片假名形状：ノ就是一撇，联系「乃」的一撇来记。

    字源：の ← 乃；ノ ← 乃。

    ノート／nooto／笔记本、笔记

は行

  • はハ

    ha

    平假名形状：左边一竖，右边的十字在下方打结；看见这个结，笑一声“哈”。

    读音提示：ha：用“哈”作近音提示。

    片假名形状：ハ就是张开的「八」，两笔分向两边，张嘴笑“哈”。

    字源：は ← 波；ハ ← 八。

    ハム／hamu／火腿

  • ひヒ

    hi

    平假名形状：像一张向上咧开的笑嘴，想到笑“嘻”的表情。

    读音提示：hi：“嘻”只帮记忆；实际要更轻，让气流靠近上腭擦出。

    片假名形状：ヒ像「匕」：上面短笔，下面一笔竖弯。

    字源：ひ ← 比；ヒ ← 比。

    ヒント／hinto／提示、线索

  • ふフ

    fu

    平假名形状：中间一弯，两边是小点；想象轻轻吹气，把碎屑吹散。

    读音提示：fu：“夫”只帮记忆；双唇轻吹，接う，上齿不咬下唇。

    片假名形状：フ像「了」去掉下面的竖钩，只留上方横折撇。

    字源：ふ ← 不；フ ← 不。

    フルーツ／furuutsu／水果

  • へヘ

    he

    平假名形状：一座小山，只有一折；爬上山，轻轻喊一声。

    读音提示：he：h 接え；借“嘿”的开头，去掉尾音 i。

    片假名形状：ヘ和へ几乎同形，也是一座小山。

    字源：へ ← 部；ヘ ← 部。

    ヘルメット／herumetto／头盔

  • ほホ

    ho

    平假名形状：在は的右边多加一横，像给结上面又搭了一层横梁。

    读音提示：ho：借“吼”hǒu 的开头，收掉尾音 u。

    片假名形状：ホ像「木」，下面两笔收成分开的短点。

    字源：ほ ← 保；ホ ← 保。

    ホテル／hoteru／酒店

ま行

  • まマ

    ma

    平假名形状：「末」上面的两横还在，下面把长笔打成一个结。

    读音提示：ma：用“妈”作近音提示。

    片假名形状：マ像「了」的横折撇下面加一小斜笔，尾巴朝右下。

    字源：ま ← 末；マ ← 万・末。

    トマト／tomato／番茄

  • みミ

    mi

    平假名形状：像一小团拧弯的米线，左边绕圈，右边伸出一根弯线。

    读音提示：mi：用“米”作近音提示。

    片假名形状：ミ就是三条略斜的短横，直接联系汉字「三」。

    字源：み ← 美；ミ ← 三。

    ミルク／miruku／牛奶

  • むム

    mu

    平假名形状：左边十字接一个小圈，右上还有一点；想成母鸡守着一枚蛋。

    读音提示：mu：“母”帮助回忆；う的嘴唇放松。

    片假名形状：ム像汉字部件「厶」，先斜下来，再绕向右。

    字源：む ← 武；ム ← 牟。

    ハム／hamu／火腿

  • めメ

    me

    平假名形状：像「女」绕成一个圈，但尾部不留ぬ的小圈；两字并排比较。

    读音提示：me：借“妹”mèi 的开头，去掉尾音 i。

    片假名形状：メ看成「乂」，就是两条长斜线交叉。

    字源：め ← 女；メ ← 女。

    メモ／memo／便条、备忘

  • もモ

    mo

    平假名形状：把「毛」最上面的一撇拿走，保留两横和竖弯。

    读音提示：mo：用“摸”帮助回忆，元音保持纯 o。

    片假名形状：モ也像「毛」少了最上面的一撇，笔画更平直。

    字源：も ← 毛；モ ← 毛。

    レモン／remon／柠檬

や行

  • やヤ

    ya

    平假名形状：一个长钩上冒出两笔，像土里冒出一棵小芽。

    读音提示：ya：用“芽”作近音提示。

    片假名形状：ヤ可联想成侧着写的「牙」；一笔向下，另一笔向右伸。

    字源：や ← 也；ヤ ← 也。

    タイヤ／taiya／轮胎

  • ゆユ

    yu

    平假名形状：看成「由」被左右拉开，像一条鱼：左边尾巴，右边肚子。

    读音提示：yu：“鱼”只作形状标签；从い滑向う，合成一拍，不读拼音 ü。

    片假名形状：ユ像抽屉的一角，下横向左伸得更长；和下横较短的コ比较。

    字源：ゆ ← 由；ユ ← 由。

    ユニフォーム／yunifoomu／制服、队服

  • よヨ

    yo

    平假名形状：上面伸出一只短手，下面绕成圆嘴，张口叫“哟”。

    读音提示：yo：用“哟”帮助回忆，元音保持纯 o。

    片假名形状：ヨ就是部件「彐」：三条横线由右边一竖连起来。

    字源：よ ← 与；ヨ ← 与。

    ヨーヨー／yooyoo／悠悠球

ら行

  • らラ

    ra

    平假名形状：上面一小点，下面像没封口的 5；想象一滴辣油滴下来。

    读音提示：ra：“辣”只作标签；r 要让舌尖轻点一下，不卷舌。

    片假名形状：ラ像「亏」把下方的钩改成斜撇，上面仍留两层横线。

    字源：ら ← 良；ラ ← 良。

    カメラ／kamera／相机

  • りリ

    ri

    平假名形状：联系「利」：左右像两把小刀，左短右长，右笔往下弯。

    读音提示：ri：“里”只作标签；r 是舌尖轻点，不是普通话 r。

    片假名形状：リ像「利」右边的「刂」，两根长短不同的竖笔。

    字源：り ← 利；リ ← 利。

    アイスクリーム／aisukuriimu／冰淇淋

  • るル

    ru

    平假名形状：像数字 3，底下“留”一个小圈；用“留圈”记住る。

    读音提示：ru：“路”只作标签；r 轻点，再接う。

    片假名形状：ル像「儿」，左边一撇，右边一笔向右挑开。

    字源：る ← 留；ル ← 流。

    ミルク／miruku／牛奶

  • れレ

    re

    平假名形状：联系「礼」：左边一竖，右边的笔画向右伸长，像伸手行礼。

    读音提示：re：借“雷”léi 的开头，去掉尾音 i，并把声母改为舌尖轻点。

    片假名形状：レ像竖弯钩「乚」，一笔落下，再向右上挑。

    字源：れ ← 礼；レ ← 礼。

    レモン／remon／柠檬

  • ろロ

    ro

    平假名形状：也像数字 3，但底下“不留圈”；和留圈的る一起记。

    读音提示：ro：r 轻点，接お的 o；“罗”只作回忆标签。

    片假名形状：ロ就是方方的汉字「口」，四边围起来。

    字源：ろ ← 呂；ロ ← 呂。

    ロープ／roopu／绳索

わ行

  • わワ

    wa

    平假名形状：左边一竖，右边张开大口；看到东西就惊讶地喊“哇”。

    读音提示：wa：用“哇”作近音提示。

    片假名形状：ワ像ウ去掉头顶的一点，像没加点的屋顶。

    字源：わ ← 和；ワ ← 和。

    ワイン／wain／葡萄酒

  • をヲ

    o（输入 wo）

    平假名形状：上方有点像ち，下面再绕一个大弯；当作需要单独认的记号。

    读音提示：o：作助词时通常读 o，键盘常输入 wo；用“哦”提示读音。

    片假名形状：ヲ像フ的弯线里多了一条横；和を一起认，单独记 o／输入 wo。

    字源：を ← 遠；ヲ ← 乎。

    コーヒーをください。／koohii o kudasai.／请给我咖啡。

拨音

  • んン

    n

    平假名形状：一笔先斜下去，再起一个小峰，像一条轻轻起伏的波浪。

    读音提示：n：鼻音独占一拍；可借“嗯”的鼻音感觉，不额外加 en。

    片假名形状：ン像一只眼睛加一条向右上挑的长笔；和末笔下落的ソ成对记。

    字源：ん ← 无；ン ← 诸说，未定。

    ペン／pen／笔

容易混淆的字，成对比较

  • き／さ：き上面两横，さ少一横。
  • ぬ／め：ぬ尾端有小圈，め不留这个小圈。
  • ね／れ／わ：ね右下打结；れ向右伸尾；わ右侧是大弯。
  • は／ほ：ほ右边比は多一横。
  • る／ろ：る底部留小圈；ろ不留圈。
  • ク／タ：ク里面空着；タ里面有一小笔。
  • ウ／ワ：ウ头顶有一点；ワ没有这点。
  • シ／ツ：シ的两点偏竖排、末笔上挑；ツ的两点偏横排、末笔向左下落。
  • ン／ソ：ン的末笔向右上挑；ソ的末笔向左下落。结合笔顺图一起练。

长音与最后一个「を」

「ー」表示前面的元音延长一拍

这份表用重复元音标长音：aa、ii、uu、ee、oo。例如カード读 kaado，节奏是 ka・a・do，共三拍；不是把「ー」读成汉字“一”。

罗马音是读音辅助，不是英语或汉语拼音；し写 shi，ち写 chi，つ写 tsu，ふ写 fu。ヘルメット中的小っ表示促音，罗马音用双写辅音表示：herumetto，读到 t 前短暂停顿。

を／ヲ：用句子学习

现代常用外来词通常不用ヲ。平假名「を」常作助词，通常读 o；键盘输入时常用 wo。不要为了凑齐字母，把旧式拼法当成现代常用词。

请给我绳索。ロープをください。ろーぷをください。roopu o kudasai.

一次练五个词就够了

  1. 看原词，联想意思，拆着读假名：カ・メ・ラ → ka・me・ra。
  2. 遮住原词与罗马音，只看假名读出来，再核对。
  3. 把新旧词打乱抽查；答错的稍后再见一次。
